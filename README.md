## 🏛️ 1. Design & Typography System

### Typography Standards
- **Primary Editorial & Statement Display Font:** `Times New Roman` (styled with generous letter-spacing, optical hierarchy, authoritative executive styling, and editorial serif headlines).
- **Secondary UI & Institutional Sans-Serif:** `Plus Jakarta Sans` / `Inter` (crisp grotesque clarity for navigation, data tables, metrics, and body copy).
- **Technical & Security Telemetry Monospace:** `JetBrains Mono` (for cryptographic hashes, SLAs, architecture specifications, and API endpoints).

### Institutional Color Palette
- **Deep Enterprise Navy:** `#0B172A` & `#070D18` (Foundational backgrounds and hero sections).
- **Light Architectural Surfaces:** `#FFFFFF`, `#F8FAFC`, `#F1F5F9` (Clean, generous executive layouts).
- **Sovereign Accents:** Sapphire Blue (`#2563EB`, `#1D4ED8`) and Royal Purple (`#7C3AED`, `#6366F1`).
- **Institutional Borders:** Subtly tinted glassmorphic slate (`#E2E8F0`, `rgba(255,255,255,0.08)`).

## ⚡ 3. Getting Started

### Prerequisites
- Node.js `v18+` or `v20+` (tested on Node v22.14.0)
- npm or pnpm

### Running in Development
```bash
npm install
npm run dev
```
The application will launch at `http://localhost:3000`.

### Building for Production
```bash
npm run build
```
Production assets are generated in `/dist` with full route-level code splitting and gzip compression.

### Previewing Production Build
```bash
npm run preview
```
